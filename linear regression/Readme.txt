# Student Package Predictor

A machine learning web application that predicts a student's placement package based on CGPA using Simple Linear Regression.

## Technologies Used

- Python
- Flask
- NumPy
- Scikit-learn
- HTML
- CSS
- Simple Linear Regression

## How It Works

1. Student enters CGPA.
2. Flask receives the CGPA.
3. The trained Linear Regression model predicts the package.
4. The predicted package is displayed in LPA.

## Input

Student CGPA

## Output

Predicted Placement Package in LPA
